1 Binary File Structure
DICOM Part 10 Byte Layout
Preamble 128 bytes 0x0000
DICM 4 bytes 0x0080
File Meta Info Group 0002 0x0084
Dataset Elements Groups 0008–7FDF variable
Pixel Data (7FE0,0010) variable
Preamble
128 zero bytes, unused by DICOS. Applications may embed info here.
Magic
ASCII "DICM" — validates the file as DICOM/DICOS Part 10.
File Meta
Always Explicit VR Little Endian. Contains Transfer Syntax UID, SOP Class.
Dataset
Encoded per Transfer Syntax. Image dimensions, modality, windowing, DICOS tags.
Pixel Data
Raw u16 values (native) or compressed frame fragments (encapsulated).
Rust mapping: The parser in reader.rs reads the preamble + magic, then decodes File Meta (always Explicit VR LE). The TransferSyntax from tag (0002,0010) determines how the remaining dataset is decoded. All elements are stored in a BTreeMap<Tag, Element> inside the Dataset struct.
2 Pixel Data Encoding
Native (Uncompressed)

Transfer syntaxes: Implicit/Explicit VR Little Endian

// PixelData for native encoding struct PixelData { is_encapsulated: false, frames: Vec<Frame>, } // Each frame: flat u16 pixel values struct Frame { data: Vec<u16>, // width × height pixels }
Pixels stored as raw u16 LE values, one Frame per image slice. For a 512×512 image, each frame holds 262,144 u16 values (512 KB).
Encapsulated (Compressed)

Transfer syntaxes: JPEG-LS, JPEG 2000, JPEG Lossless, RLE

BOT offset[0] offset[1] …
Item Frame 0 compressed
Item Frame 1 compressed
Item Frame N compressed
Delim FFFE,E0DD
BOT
Basic Offset Table — byte offsets to each frame item
Items
Each wraps one frame's compressed bitstream in Vec<u8>
Delim
Sequence Delimitation Item terminates the pixel data

// Volume voxel access let idx = z * dim_y * dim_x + y * dim_x + x; let voxel = volume.data[idx]; // Each z-slice = one Frame // Total: dim_x × dim_y × dim_z voxels // Example: 512×512×256 = 67M voxels // = 128 MB (u16)
DICOS pixel format: Always MONOCHROME2 photometric interpretation with 16 bits allocated, 1 sample per pixel. Unsigned by default (PixelRepresentation = 0). CT values are mapped via RescaleSlope × raw + RescaleIntercept to Hounsfield Units.
